# Kit TP 4 — parcours Data / Cyber

Fiche de TP : « TP 4 · parcours Data / Cyber » (fournie par l'enseignant).

| Partie | Fichier | Pour qui | Vérification |
|---|---|---|---|
| A · Reconnaître | (fiche papier : 6 extraits QueenBee) | tous | correction en séance |
| B1 · Étendre sans modifier | `extension-canal.js` | tous | `npm run tp4` |
| B2 · Ordre des décorateurs | `ordre-decorateurs.js` | tous | `node seance4-patterns/tp-data-cyber/ordre-decorateurs.js` |
| C · Data : Adapter | `sources-mesures.js` | binômes Data | `npm run tp4` |
| C · Cyber : Proxy | `proxy-roles.js` | binômes Cyber | `npm run tp4` |
| D · Justifier | `PATTERNS.md` (à créer) | tous | relu par l'enseignant |

`npm run tp4` lance tous les tests du kit : un binôme Data peut ignorer les échecs
de `proxy-roles.spec.js`, un binôme Cyber ceux de `sources-mesures.spec.js`.
Pour ne lancer qu'un fichier : `node --test seance4-patterns/tp-data-cyber/sources-mesures.spec.js`
